# Project Rules

2. Never rename folders.

3. Never change finalized assets without discussion.

4. Test after every coding step.

5. Keep the website elegant and uncluttered.

6. Every new design must answer:

"Does this feel like a luxury handcrafted Garhwali wedding invitation?"

If the answer is NO,

don't add it.
